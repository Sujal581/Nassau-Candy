# Nassau Candy Logistics Intelligence Platform

A futuristic **Streamlit dashboard** for analyzing Nassau Candy shipping and distribution data with interactive analytics, logistics insights, and a premium cyberpunk UI.

---

## 🚀 Features

- 📦 Shipment & Distribution Analytics  
- 🌍 Route & Geographic Insights  
- 🚚 Ship Mode Performance Tracking  
- 🏭 Factory & Division Analysis  
- 📊 Interactive KPIs & Visualizations  
- 🎨 Futuristic Neon UI  
- 🔍 Dynamic Global Filters  
- 📂 CSV Upload & Processing  
- ⚡ Fast Cached Data Loading  

---

## 🖥️ Dashboard Pages

| Page | Description |
|---|---|
| 📊 Overview | Business KPIs & shipment summary |
| 🛣️ Route Analysis | Route efficiency & delay analysis |
| 🌍 Geographic | State-wise shipment insights |
| 🚚 Ship Mode | Shipping method comparison |
| 🏭 Factory Division | Division performance analytics |
| 🔎 Data Explorer | Interactive dataset exploration |

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit  
- **Processing:** Pandas  
- **Visualization:** Plotly  
- **Styling:** Custom CSS
